# SustainScore

SustainScore is a student project for the **Principles of Software Development** course at the University of Luxembourg.

The goal of the project is to design, build, test, and evaluate a small but complete mobile application while applying software development principles such as requirements engineering, design, implementation, CI/CD, testing, and project documentation.

## Project Overview

SustainScore is a mobile application that helps users become more aware of their daily resource consumption habits. Users can log predefined activities, view a sustainability score, compare their behavior with a recommended profile, and receive improvement suggestions.

## Key Features

- Activity logging for predefined resource-related actions.
- Sustainability score calculation.
- Visual comparison between actual and recommended behavior.
- Daily and weekly progress summaries.
- Rule-based daily feedback with actionable suggestions.

## Project Phases

The project follows the course delivery phases:

1. Idea and scoping
2. Requirements
3. Cost and complexity analysis
4. Design
5. Implementation
6. CI/CD
7. Testing
8. Final report and demo

## Repository Status

The app is complete. The repository contains the Android source code (Kotlin, Jetpack Compose), unit and UI tests, GitHub Actions CI/CD workflows, and documentation for all project phases.

## Development Practices

The project will follow modern software development principles:

- Git version control with meaningful commits.
- Incremental development through milestones.
- Modular design.
- Automated tests for important calculation logic.
- CI/CD using GitHub Actions.
- Documentation of requirements, design decisions, and development progress.
